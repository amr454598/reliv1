# Project Name Reliv
تطبيق بيجمعلك كل الطرق للتخلص من كراكيبك في مكان واحد؛ بيع حاجاتك، بدلها بحاجة تلزمك، اتبرع بيها لغيرك، أو سلمها لإعادة التدوير ، وكل ده بمعاملات آمنة.

Work Plan
Phase 1: Research & User Experience (Week 1)
Market and competitor analysis, defining User Personas, and mapping the User Journey for the 4 core paths (Sell, Swap, Donate, Repair & Recycle).

Phase 2: Information Architecture & Design System (Week 2)
Building the Sitemap, wireframing screen layouts, and establishing the Design System & Design Tokens (neon palette, typography, reusable components) in Figma.

Phase 3: High-Fidelity UI Design (Weeks 3 - 4)
Designing the mobile app screens for all core paths, AI listing features, and the Admin Dashboard with the Repair Hubs GIS map.

Phase 4: Interactive Prototyping & Testing (Week 5)
Building clickable Interactive Prototypes (Smart Animate) in Figma, conducting usability reviews, and preparing the final presentation and documentation.
App performance testing, reviewing user flows, and preparing the final project documentation and presentation.

KPIs (Key Performance Indicators)

User Flow Efficiency: High task success rate (above 95%) during interactive prototyping tests for the 4 main paths.
Visual Consistency: 100% adherence to the defined Design System, components, and neon dark-mode token system in Figma.
Information Architecture Clarity: Seamless navigation transitions, quick information retrieval, and clear visual hierarchy verified through prototype testing.
Milestone Delivery: Successful handover of all Figma frames, design documentation, and presentation decks on schedule.
